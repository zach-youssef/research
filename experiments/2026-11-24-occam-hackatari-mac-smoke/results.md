
Exploratory, so not reproduced by the supervisor's 7a step. Tolerances from plan.md:
`pong_pixel_orig_mean`, `pong_pixel_lazy_enemy_mean`, `pong_planes_orig_mean`,
`pong_planes_lazy_enemy_mean` within 5; the eight `breakout_{pixel,binary,classes,planes}_{orig,red}_mean`
within 25%; `freeway_pixel_orig_mean` and `freeway_pixel_stop_all_cars_mean` within 3. A rerun
reproduces when every criterion's verdict is unchanged and each toleranced metric is within its
tolerance. (Same seeds on the same machine should repeat exactly; across machines floating-point
differences can flip sampled actions.)

## Notes

What the run shows (n = 10 episodes per cell, seed-0 checkpoints; exploratory, so verdicts are
capped at inconclusive, and the criteria's branches were all `supports`):

- **It runs.** No patch of upstream code was needed: OCAtariWrappers' own `load_agent` and
  wrappers, HackAtari `3b5fc32`, OCAtari 2.1.0, gymnasium 0.29.1, ale-py 0.9.1 (ROMs bundled),
  torch 2.7.1, CPython 3.11, all with arm64 wheels. Differences from upstream's `requirements.txt`:
  no stable-baselines3 or rliable (FIRE-on-reset re-implemented), pygame 2.6.1 instead of 2.1.0,
  matplotlib 3.10, ale-py 0.9.1 instead of the paper's 0.8.1, and HackAtari from git (the PyPI
  `hackatari` 0.0.6 is a stub; the repo's own setup.py says 0.0.6 too, so the commit is the pin).
- **C8 (Pong `lazy_enemy`).** Pixel PPO 12.2 -> -16.9 (paper PPO 18 -> -15), Planes 19.1 -> 12.1
  (paper 19 -> 17), Binary 17.9 -> 15.9. The other mask agents were hit harder than the paper's
  Planes row: Class masks 19.2 -> -10.6, Object masks 17.9 -> 1.2, object vector 17.0 -> -14.3.
  So "object-centric holds" is agent-specific here (Binary, Planes). The object-vector collapse
  agrees with the paper's Semantic Vector row (19 -> -20); the paper's Table 6 numbers for the
  Class and Object mask agents were not compared, so those two rows are not a deviation or an
  agreement. `hidden_enemy` leaves the
  pixel agent exactly unchanged (same seeds, identical returns, since it only edits the OCAtari
  object list) and collapses the object-vector agent to -20.5, the expected asymmetry.
- **C9 (Breakout red paddle and ball).** Pixel PPO 92.4 -> 7.6 (paper 391 -> 4); Binary, Class
  and Planes mask agents are identical to the original, to the episode, because the recolour
  changes no RAM-derived object (same seeds, same actions: identical by construction, not
  evidence of robustness beyond the observation not changing); Object masks (grey pixels inside
  boxes) 133.0 -> 20.8 (paper 216 -> 99, also a drop). Our original-game scores are lower than
  the paper's for pixel PPO (92 vs 391) and truncated episodes exist (below).
- **C11 (Freeway `stop_all_cars`).** Pixel PPO 32.2 -> 0.0 (paper PPO 7.6), Binary 33.4 -> 1.0,
  while Class (40.0), Object (32.6), Planes (38.9) and object vector (33.6) hold or rise (paper
  SCoBots 30 -> 41). The paper's PPO (7.6) is not a zero. Class masks' 40.0 on every seed is real:
  the reviewer ran an always-UP policy in the same environment (seeds 0 and 3) and it scores 41
  in the full 2048 steps; the tunnel variant parks the cars at x=35/55 and leaves the chicken's
  column clear, and the NOOP start shortens episodes to about 2019-2044 steps, so 40 is the
  time-limit ceiling for a policy that just presses UP, which this agent apparently does.
- **Truncation.** 9 of 420 episodes hit the 10,000-step cap, all in Breakout (Binary seeds 2, 3,
  6, Class masks seed 5, pixel seed 5 in the original; the red condition repeats the mask ones),
  with returns 245 to 379; their returns are lower bounds. The agents probably stall without
  losing the last ball (upstream's evaluation has no no-progress limit); not investigated.
- **Timing (CPU, one thread, M4).** Policy forward plus sampling 0.70 ms per step, environment
  step (frameskip 4, HackAtari/OCAtari object detection, mask building) 0.78 ms, so about 670
  steps per second; Pong episodes are about 1000 to 4500 agent steps. Load time (read +
  `torch.load` + model build, warm page cache): 39 to 82 ms for the pixel and mask agents, 83 to
  122 ms for the object-vector agent (10.5 MB file vs 6.8 MB). No MPS numbers.
- **Weights and licences.** Weights are files in `VanillaWhey/OCAtariWrappers` (commit
  `057afc4e`, 2026-04-21), 18 files for the three games, 134 MB, hashes in `results.json`;
  code and weights are under the repo's MIT licence (Copyright 2025 Cedric Derstroff; no
  separate weights licence). HackAtari and OCAtari are MIT. `torch.load` runs with torch 2.7.1's
  default `weights_only=True` and accepted the files, so no arbitrary-code pickle path.
- **Going further.** The same driver covers the other four games' checkpoints in that repo
  (Boxing, Frostbite, MsPacman, Skiing) by adding them to `GAMES`; the paper's 30 episodes,
  epsilon 0.001 and the pixel agents' paper numbers need the other agents (DQN, C51, i-DQN from
  other repos, IMPALA on envpool/Linux). Training (CleanRL PPO, 2e8 frames, 4 to 6 h on an A100
  per paper C12) is a TheaterPC/CUDA job; the Mac is enough for evaluation, the mask agents'
  training (40M frames) might fit a day of CPU but is not tested.
- **Cost.** Downloads estimated (not measured) at about 400 MB (weights 118 MB packed in the git history, venv wheels about
  250 MB, Python and uv about 40 MB), within the 500 MB cap; about 75 min of wall clock including the
  two failed starts.
